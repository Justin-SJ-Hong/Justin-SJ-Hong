## 🌟 About Me
사용자 경험(UX) 개선과 구조적인 설계를 중심으로 개발하는  
**React · TypeScript 프론트엔드 개발자** 홍엽입니다.

MSA, 커머스, 추천 서비스, 콘텐츠 플랫폼, 관리자 서비스 등  
다양한 도메인에서 프로젝트를 수행하며 총 **27개 기능**, **15개 API**를 직접 구현했습니다.  

리뷰 렌더링 최적화(50% 개선), UI 중복제거(40% 감소),  
Git Flow 도입(충돌 50~60% 감소) 등 사용자/팀 생산성을 높이는 경험을 중요하게 생각합니다.

최근에는 O2O 플랫폼, 커뮤니티 서비스, 계약/결제 플랫폼 등  
실제 사용자 경험에 크게 영향을 주는 서비스 개발에 관심이 많습니다.
